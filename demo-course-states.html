Course Component - Interactive Demo

This demo showcases the two states of the Course component: Locked and Unlocked. Click the links below to view each state in action.

LOCKED STATE

🔒 Locked Course (User hasn't passed previous quiz)

  • Displays info message about completing previous quizzes
  • "Begin" button is disabled
  • All lessons except "Intro" are locked with lock icons
  • Shows "Lesson: 0/5"
  • Only the "Intro" lesson is accessible
View Locked State
UNLOCKED STATE

🔓 Unlocked Course (User passed previous quiz)

  • Shows both "Take the Quiz" and "Begin" buttons (active)
  • Completed lessons show green checkmarks
  • Shows "Lesson: 4/5" indicating progress
  • "Ready?" divider appears before the Quiz section
  • Red notification dot on one completed lesson
  • Current lesson highlighted with background color
View Unlocked State

🚀 Getting Started
