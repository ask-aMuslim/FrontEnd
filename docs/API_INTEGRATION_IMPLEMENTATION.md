# API Integration Implementation Guide

## Overview

This document describes the production-grade, contract-enforced API integration system implemented for the AskAMuslim Angular 20 frontend.

## Architecture Principles

1. **Swagger is the single source of truth** - All API clients are generated from the OpenAPI spec
2. **No manual API wiring** - Components never call HttpClient directly
3. **Contract drift detection** - CI fails if backend changes without frontend regeneration
4. **HttpContextToken pattern** - No fragile URL matching for interceptor behavior
5. **Memory-first token storage** - Secure JWT handling with localStorage fallback

## Core Components

### 1. HttpContextTokens

Type-safe request configuration without URL matching:

```typescript
import { SKIP_AUTH, SKIP_ERROR_HANDLING, SKIP_TOKEN_REFRESH } from '@core/http';

// Skip authentication for public endpoints
this.http.get(url, { 
  context: new HttpContext().set(SKIP_AUTH, true) 
});

// Handle errors locally instead of globally
this.http.get(url, { 
  context: new HttpContext().set(SKIP_ERROR_HANDLING, true) 
});
```

Available tokens:
- `SKIP_AUTH` - Skip JWT injection for this request
- `SKIP_ERROR_HANDLING` - Skip global error interceptor
- `SKIP_TOKEN_REFRESH` - Don't attempt token refresh on 401
- `IS_REFRESH_REQUEST` - Internal: marks refresh endpoint calls
- `RETRY_COUNT` - Custom retry count for resilient requests
- `CUSTOM_TIMEOUT` - Custom timeout in milliseconds

### 2. TokenService

JWT lifecycle management with Angular signals:

```typescript
import { TokenService } from '@core/auth';

@Injectable({ providedIn: 'root' })
export class MyService {
  tokenService = inject(TokenService);
  
  // Check authentication
  if (this.tokenService.isAuthenticated()) {
    // User is logged in
  }
  
  // Set tokens after login
  this.tokenService.setTokens({
    accessToken: '...',
    refreshToken: '...',
    expiresIn: 3600,
    userId: '123',
    userEmail: 'user@example.com'
  });
  
  // Clear tokens on logout
  this.tokenService.clearTokens();
  
  // Get valid token (may trigger refresh)
  this.tokenService.getValidToken().subscribe(token => {
    // Use token
  });
}
```

Features:
- Memory-first storage with localStorage fallback
- Automatic token refresh when expiring within 1 minute
- Computed signals for reactive state
- SSR-safe (checks platform before localStorage access)

### 3. RefreshQueueService

Prevents parallel token refresh requests:

```typescript
import { RefreshQueueService } from '@core/auth';

// If refresh is in progress, waits for it
// If not, initiates new refresh
this.refreshQueue.queueRefresh().subscribe(newToken => {
  // Use new token
});
```

### 5. Error Handling

Normalized error structure:

```typescript
interface ApiError {
  statusCode: number;
  message: string;
  validationErrors: Record<string, string[]>;
  traceId: string | null;
  timestamp: Date;
  isNetworkError: boolean;
  isAuthError: boolean;
  isValidationError: boolean;
  readonly originalError?: unknown;
}
```

Usage:

```typescript
import { ErrorNormalizer } from '@core/errors';

@Injectable({ providedIn: 'root' })
export class MyService {
  errorNormalizer = inject(ErrorNormalizer);
  
  handleError(error: unknown) {
    const apiError = this.errorNormalizer.normalize(error);
    
    if (apiError.isValidationError) {
      // Show validation errors
      console.log(apiError.validationErrors);
    } else if (apiError.isNetworkError) {
      // Show network error message
      alert('No internet connection');
    } else {
      // Show generic error
      alert(apiError.message);
    }
  }
}
```

### 6. IdentityFacade

Domain-specific wrapper for authentication:

```typescript
import { IdentityFacade } from '@core/api/facades';

@Component({...})
export class LoginComponent {
  identityFacade = inject(IdentityFacade);
  
  login(credentials: LoginViewModel) {
    this.identityFacade.login(credentials).subscribe({
      next: () => {
        // Navigate to home
        this.router.navigate(['/']);
      },
      error: (error: ApiError) => {
        // Error already normalized
        this.errorMessage = error.message;
      }
    });
  }
  
  logout() {
    this.identityFacade.logout().subscribe(() => {
      // Redirect to login
    });
  }
}
```

## CI/CD Integration

### Contract Drift Detection

The GitHub Actions workflow (`.github/workflows/api-contract.yml`) automatically:

1. Fetches the latest Swagger JSON from the backend
2. Regenerates the API client
3. Checks for changes in the generated folder
4. Fails the build if contract drift is detected

```yaml
# Manual trigger to regenerate API client
gh workflow run api-contract.yml
```

### Local Regeneration

```bash
# Regenerate API client from Swagger
npm run generate:api
```

## Migration Checklist

### From Legacy ApiService to Generated Clients

1. **Identify legacy endpoints**
   - Find all usages of `ApiService` and `API_ENDPOINTS`
   - List all endpoints being called

2. **Verify endpoint exists in Swagger**
   - Check `https://ask-a-muslim.runasp.net/swagger`
   - If missing, backend needs to expose it

3. **Create/update facade method**
   ```typescript
   // Before (legacy)
   this.apiService.get<Course[]>('courses').subscribe(...)
   
   // After (generated)
   apiCourseGetCoursesGet(this.http, this.config.rootUrl)
     .pipe(map(r => r.body))
     .subscribe(...)
   ```

4. **Update component to use facade**
   - Inject facade instead of ApiService
   - Use facade methods

5. **Remove legacy code**
   - Delete endpoint constant from API_ENDPOINTS
   - Remove unused ApiService methods

## Best Practices

### DO:
- Use facades for all API calls
- Use HttpContextToken for interceptor configuration
- Handle errors using ErrorNormalizer
- Let the interceptor handle token refresh
- Regenerate API client when backend changes

### DON'T:
- Call HttpClient directly from components
- Modify generated files
- Use URL matching in interceptors
- Store tokens in components
- Bypass the facade layer

## Troubleshooting

### "No authentication token available"
- User is not logged in
- Token has expired and refresh failed
- Solution: Redirect to login

### "Contract drift detected" in CI
- Backend API has changed
- Solution: Run `npm run generate:api` locally and commit changes

### "Refresh token failed"
- Refresh token has expired
- Solution: Clear tokens and redirect to login

### Type errors after regeneration
- Generated types may have changed
- Solution: Update facade methods to match new types
